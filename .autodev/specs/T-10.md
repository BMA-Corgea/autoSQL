# T-10 — The correctness harness fingerprints the wrong runtime

**Spawned by:** T-6 (`FINDINGS.md` §7) · **Authority:** GA-15 (*"Loop until everything is closed"*)

## The defect

Every battery printed `runtime.sql sha256=…` by hashing **the file the harness expects**
(`spikes/T-1/proto/runtime.sql`) rather than the functions actually installed. During T-6 that made
**all 42 outputs claim T-3's runtime while the database held T-6's patched one.** The results were
right; the provenance line on every single one of them was wrong.

It was caught only because a probe was written specifically to check it. **A fingerprint that
reports what you hoped is installed is not a fingerprint** — and this one sits on the instrument
that decides whether this project ships.

## The fix

Read `pg_get_functiondef` over schema `xpr` and report **both**, flagging a mismatch in words that
say what it means:

```
runtime.sql sha256=1c58d548a6045aa6  (file on disk)
xpr schema  sha256=1e35a4933f915b81  (INSTALLED -- this is what ran)
NOTE: installed runtime differs from .../proto/runtime.sql.
      That is EXPECTED when a ticket installs its own build;
      it is a DEFECT if you believed they were the same.
```

Three files: `differ.py` gains `installed_runtime_sha()`, `H_ast_fuzz.py` prints both,
`conformance.py` records `runtime_installed_sha256` in its meta.

## Acceptance criteria

- **AC-1** — a battery prints both fingerprints and flags a mismatch. *Test:* run one against a
  database holding a different build than the file.
- **AC-2** — `conformance.py`'s meta carries `runtime_installed_sha256`. *Test:* call it.
- **AC-3** — a provenance line **never** fails a run. *Test:* the unreachable-database path returns
  a marker rather than raising.
- **AC-4** — the two implementations agree. *Test:* both report the same sha for the same database.
- **AC-5** — nothing digest-cited is edited. `differ.py`, `H_ast_fuzz.py` and `conformance.py` carry
  no cited digests (checked); the three that do are untouched.

## Out of scope

Re-running T-6's batteries. Its results stand — §7 already established, with an independent probe,
which runtime produced them. This fixes the instrument so the next run does not need a probe.
